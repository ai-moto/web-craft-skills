Included skills

Sixteen focused skills cover the important lanes for most websites and apps without pulling in private project details.

Showing all 16 skills.

$web-build-coach

Build educational websites while explaining important architecture and implementation decisions.

$web-design-director

Shape responsive visual hierarchy, UX layout, design systems, typography, color, and components.

$web-motion-polish

Add purposeful, accessible animation and micro-interactions without slowing down the interface.

$web-brand-assets

Create and review logos, icons, favicons, app icons, and social preview asset implementation.

$web-content-quality

Improve copy, CTAs, claims, docs, empty states, errors, and trust-building language.

$web-accessibility-audit

Audit keyboard navigation, semantics, labels, contrast, zoom, forms, and reduced motion.

$web-security-review

Review authorized websites for practical risks, evidence, minimal fixes, and remaining test gaps.

$web-legal-compliance

Review privacy, terms, cookie notices, consent, legal links, and public trust gaps.

$web-seo-findability

Check metadata, crawlability, sitemap, robots, social previews, and indexing readiness.

$web-email-launch

Verify transactional email, sender domains, SPF, DKIM, DMARC, and inbox tests.

$web-performance-audit

Improve speed, Core Web Vitals, image weight, bundle size, caching, and layout shift.

$web-analytics-observability

Verify analytics, funnels, errors, web vitals, bot protection, and launch dashboards.

$web-payments-launch

Check checkout, subscriptions, webhooks, paywalls, receipts, refunds, and live-mode gates.

$web-deployment-ops

Verify hosting, DNS, SSL, redirects, env config, cache, source maps, and rollback readiness.

$web-core-flow-testing

Walk signup, login, forms, links, checkout, account, mobile, browser, 404, and error flows.

$web-launch-qa

Orchestrate final PASS/FAIL/BLOCKED launch readiness across the full web surface.

Install

Install as repo-scoped skills for one project, or as user skills when you want them across projects.

mkdir -p .agents/skills
cp -R web-craft-skills/skills/* .agents/skills/

Restart Codex if newly copied skills do not appear. Invoke skills explicitly with the `$skill-name` syntax.
